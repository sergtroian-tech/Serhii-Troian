# NexusMail — Почтовый клиент и Планировщик Задач

Современный почтовый клиент со встроенным планировщиком задач (расписание Agenda, Канбан-доска, Матрица приоритетов Эйзенхауэра), интеграцией с Gmail и поддержкой горячих клавиш.

## Быстрый запуск

1. Установите зависимости:
```bash
npm install
```

2. Запустите локальный сервер разработки:
```bash
npm run dev
```

3. Откройте в браузере:
```
http://localhost:3000
```

## Возможности

- **Сплит-режим работы**: почта и планировщик задач на одном экране;
- **Превращение писем в задачи**: создание задачи из любого письма в 1 клик с двусторонней связью;
- **3 представления планировщика**: Расписание на день/неделю, Канбан-доска и Матрица приоритетов;
- **Интеграция с Gmail**: безопасный вход через Google и чтение/отправка реальных писем;
- **Темная и светлая тема**: автоматическое переключение с сохранением настроек;
- **Шорткаты**: быстрое управление с клавиатуры (`C`, `T`, `1`, `2`, `3`, `/`, `?`).

## Стек технологий

- React 19 + TypeScript
- Vite
- Tailwind CSS v4
- Firebase Auth (Google Workspace OAuth)
- Lucide React Icons
